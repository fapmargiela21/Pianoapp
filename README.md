# 🎹 Пианино — тренажёр

Веб-приложение для iPad: падающие ноты + клавиатура, микрофон слушает настоящее пианино,
и игра **ждёт, пока ты сыграешь правильную ноту**. Неверная нота подсвечивается красным.
Без подписок, песни добавляются сюда в репозиторий.

## Как открыть на iPad

Микрофон в браузере работает только по `https://`, поэтому приложение публикуется через GitHub Pages:

1. На GitHub открой репозиторий → **Settings → Pages**.
2. В «Build and deployment» выбери **Source: Deploy from a branch**, ветку
   `claude/piano-training-app-v577ce` (или `main`, если её смержили) и папку `/ (root)`. Нажми **Save**.
3. Через минуту появится ссылка вида `https://<логин>.github.io/Pianoapp/`.
4. Открой её в Safari на iPad → кнопка «Поделиться» → **«На экран Домой»**. Теперь это значок-приложение на весь экран.
5. При первом запуске нажми «🎤 Включить микрофон» и разреши доступ.

> GitHub Pages бесплатен для публичных репозиториев. Для приватного нужен платный GitHub.

## Как играть

- Поставь iPad на пюпитр, звук пианино должен хорошо доходить до микрофона.
- Два вида (⚙️ → «Вид»): **Ноты** — нотный стан едет под неподвижной линией, неактивная рука серая;
  **Полосы** — ноты падают сверху на клавиатуру (синие — правая рука, оранжевые — левая).
- Два режима:
  - **Ждать ноту** — приложение останавливается, пока ты не сыграешь правильную ноту.
  - **В темпе** — жмёшь большую кнопку ▶, после отсчёта ноты едут сами, а ты играешь вместе с ними.
    Попал вовремя — нота зелёная, пропустил — красная. Темп меняется кнопками −/+, есть метроном.
- Переключатель **Левая / Обе / Правая** — учить руки по отдельности.
- **▶︎ Послушать** — приложение само сыграет кусок с текущего места (темп — в настройках).
- Потяни поле с нотами пальцем вверх/вниз, чтобы начать с другого места, или нажми на полоску прогресса.
- В ⚙️ настройках: названия нот (До-Ре-Ми / C-D-E), чувствительность микрофона, масштаб.
  Голубые точки на клавишах показывают, что сейчас слышит микрофон — удобно для проверки.
- Можно играть и без пианино, нажимая клавиши на экране.

## Как добавить песню

**Проще всего:** пришли в чат Claude ссылку на YouTube и ноты (фото/скан/PDF) или MIDI-файл —
песня будет переложена в формат приложения и появится в списке.

**Сам с iPad:** кнопка «📂 Открыть MIDI» на главном экране — любой `.mid` файл
(например, скачанный с musescore.com) откроется сразу. Такие песни хранятся только на этом устройстве.

**Из записи, сам с iPad:** кнопка «🎵 Из аудио» — выбери mp3/m4a/wav или запись экрана, и нейросеть
(Basic Pitch от Spotify) прямо на iPad распознает ноты, расставит такты, тональность и руки.
Работает только на **фортепианной** записи (лучше всего — видео-урок с падающими нотами);
песня с вокалом, битом или оркестром превратится в кашу. Минута записи — примерно минута работы.
Это быстрый вариант: если песню хочешь учить всерьёз, пришли файл в чат — там распознавание
точнее (Transkun) и ноты проверяются.

> Ссылку на YouTube приложение принять не может: браузер не даёт сайту скачивать с YouTube,
> а серверы YouTube блокирует. Аудио нужно сначала сохранить на iPad (или записать экран со звуком).

## Формат песен (`songs/*.song`)

```
title: Ода к радости
artist: Л. ван Бетховен
bpm: 100            # темп (четверти в минуту)
time: 4/4           # размер
difficulty: 2       # 1–5 звёзд
key: G              # тональность (знаки при ключе): C, G, F, Bb, Am, Em...
youtube: https://youtu.be/...

[R]                 # правая рука
E4@3/4 E4 F4 G4 | G4 F4 E4 D4 | C4 C4 D4 E4 | E4. D4/8 D4/2 |
[L]                 # левая рука
C3/1 | G2 | C3 | G2 |
```

- Нота: буква `A–H` + `#`/`b` + октава (`C4` — до первой октавы, `A4` = 440 Гц).
- Длительность после `/`: `/1` целая, `/2` половинная, `/4` четверть, `/8`, `/16`.
  Запоминается для следующих нот. Точка `.` — с точкой, `t` — триоль (`/8t`).
- Аккорд: `[C4 E4 G4]/2`. Пауза: `r` (`r/8`). Лига: `~` в конце (`C4/2~ C4/8`).
- Аппликатура (номер пальца): `@3`, например `E4@3/4`.
- `|` — тактовая черта; проверка `node tools/check-songs.mjs` сообщит, если в такте не та длительность.
- Секций `[R]` и `[L]` может быть сколько угодно — каждая рука продолжает с того места, где остановилась.
- Новый файл нужно добавить в `songs/index.json`.

## Устройство

- `index.html`, `css/style.css` — интерфейс.
- `js/pitch.js` — распознавание нот с микрофона (спектр + гармоники, поиск момента удара по клавише).
- `js/render.js` — падающие ноты и клавиатура на canvas.
- `js/sheet.js` — нотный стан (шрифт Bravura, лицензия SIL OFL — `fonts/`).
- `js/songs.js` — разбор `.song` и MIDI-файлов.
- `js/audio-import.js`, `js/transcribe.js` — «Из аудио»: нейросеть Basic Pitch (`js/vendor/`, собирается
  `tools/basic-pitch/build.sh`) и расстановка нот по сетке темпа, рукам и тактам.
- `js/synth.js` — простой синтезатор для «Послушать».
- `js/app.js` — логика: ожидание правильной ноты, ошибки, прогресс.
